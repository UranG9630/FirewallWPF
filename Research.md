# Research

## Firewall

Main options to interact with the firewall:
- Control Panel - Firewall.cpl module
- WF.msc
- CMD - netsh.exe
- PS - NetSecurity module (Get-NetFirewallRule, GetNetFirewall(...)Filter)
- C/Cpp FirewallAPI.dll (https://learn.microsoft.com/en-us/windows/win32/api/_ics/ ; netfw.h)
- Registry @
  - HKLM:\System\CurrentControlSet\Services\SharedAccess\Defaults\FirewallPolicy\FirewallRules
