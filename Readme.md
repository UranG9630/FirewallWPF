# FirewallWPF

App for managing windows firewall

## MVP

- You can do CRUD operation on firewall rules as visible in built-in WF.msc tool

## Could-Haves

- UI hides meaningless filters (any, all, etc.)
- Integration with Netstat/PID to easily find app listening on given port and its corresponding rule
- Find invalid rules pointing to non-existent executables, IPs, IPsec tunnels or similar
